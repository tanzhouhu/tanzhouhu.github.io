# tanzhouhu.github.io

Personal academic homepage of **Zhouhu Tan (谭周湖)** — https://tanzhouhu.github.io

## Structure

```
index.html          # Homepage
cv/index.html       # CV page
404.html            # Not found
assets/css/main.css # Styles (light / dark themes)
assets/js/main.js   # Theme toggle, scroll reveal, nav
images/             # Avatar & favicons
```

Static site, no build step. `.nojekyll` is set so GitHub Pages serves files as-is.

## Local preview

```bash
python -m http.server 8000
# open http://127.0.0.1:8000
```
